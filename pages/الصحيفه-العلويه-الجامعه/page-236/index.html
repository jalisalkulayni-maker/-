صفحة 236

ص: 235

ظُبَةَ مِدْیَتِه(1) واَرْهَفَ لی شَبا حَدِّه(2) ودافَ(3) لی قَواتِلَ سُمُومِه، وسَدَّدَ لی صَوائِبَ سِهامِه، واَضْمَرَ اَنْ یَسُومَنِ_ی الْمَکْرُوهَ، وَیُجَرِّعَنی ذُعافَ(4) مَرارَتِه، فَنَظَرْتَ یا اِلهی اِلی ضَعْفی عَنْ احْتِمالِ الْفَوادِحِ وَعَجْزی عَنِ الاِْنْتِصارِ مِمَّنْ قَصَدَنی بِمُحارَبَتِه، وَوَحْدَتی فی کَثیرِ مَنْ ناوانی، وَاَرْصَدَ لی فیما لَمْ اُعْمِلْ فیهِ فِکْری فِ_ی الاِْنْتِصارِ مِنْ مِثْلِه

فَاَیَّدْتَنی یا رَبِّ بِعَوْنِکَ، وَشَدَدْتَ اَزْری(5) بِنَصْرِکَ، ثُمَّ فَلَلْتَ لی حَدَّهُ وَصَیَّرْتَهُ بَعْدَ جَمْعِ عَدیدِه وَحْدَهُ، وَاَعْلَیْتَ کَعْبی(6) عَلَیْهِ، وَرَدَدْتَهُ حَسیرا، لَمْ یَشْفِ غَلیلُهُ، وَلَمْ تَبْرُدْ حَراراتُ غَیْظِه (وَ) قَدْ عَضَّ عَلَیَّ شَواهُ، وَابَ مُوَلِّیا قَدْ اَخْلَفَتْ سَرایاهُ، وَاَخْلَفْتَ امالَهُ

اللّهُمَّ وَکَمْ مِنْ باغٍ بَغی عَلَیَّ بِمَکائِدِه، وَنَصَبَ لی شَرَکَ مَصائِدِه وَاَضْبَاَ اِلَیَّ اِضْباءَ(7) السَّبُعِ لِطَریدَتِه، وَانْتَهَزَ فُرْصَتَهُ وَاللِّحاقَ بِفَریسَتِه وَهُوَ یُظْهِرُ بَشاشَةَ الْمَلِقِ، وَیَبْسُطُ اِلَیَّ وَجْها طَلِقا

فَلَمّا رَاَیْتَ یا اِلهی دَغْلَ سَریرَتِه وَقُبْحَ طَوِیَّتِه(8) اَ نْکَسْتَهُ لاُِمِّ رَأْسِه فی زُبْیَتِه(9) وَاَرْکَسْتَهُ(10) فی مَهْوی حُفَیْرَتِه، وَاَ نْکَصْتَهُ(11) عَلی عَقِبِه وَرَمَیْتَهُ بِحَجَرِه، وَنَکَأْتَهُ بِمِشْقَصَتِه(12) وَخَنَقْتَهُ بِوَتَرِه، وَرَدَدْتَ

1- : أحدَّ لِقَتْلی السیف أو غیره ذا شفرة کبیرة.
2- : رقَّقَ وَحَدَّ طَرفَهُ.
3- : أَذابَ وَخَلَط.
4- السمّ القاتل فی ساعته.
5- أَیْدی (المهج والعلویّة: 1).
6- : شَرَفی وَمَجْدی.
7- اَضْبَأَ إلَیَّ ضبوءَ (العلویة: 1) : لجأ.
8- : حِقْدَ باطِنه وقُبح نیّته.
9- : حُفرته.
10- : قلبت أوّله علی آخره.
11- : أحجمت.
12- : جرحته وقتلته بسهم فیه نصل عریض.
