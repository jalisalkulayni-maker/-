صفحة 395

ص: 393

سَلامِکَ بِاَدْوَمِه، وَبارِکْ عَلَیْهِمْ (وَعَلیَّ ) وَعَلی والِدَیَّ مَعَهُمْ وَعَلَی الْمُؤْمِنینَ

ثم سلّم، وقل بعد التسلیم: اللّهُمَّ اِنّی اُشْهِدُکَ وَکَفی بِکَ شَهیدا وَ(اِنّی) اَشْهَدُ اَ نَّکَ اَ نْتَ اللّه ُ رَبّی، وَاَنّ رَسُولَکَ مُحَمَّدا صَلَّی اللّه ُ عَلَیْهِ وَالِه نَبِیّی وَاَنَّ الدِّینَ الَّذی شَرَعْتَ لَهُ دینی، وَاَنَّ الْکِتابَ الَّذی اَ نْزَلْتَهُ عَلَیْهِ کِتابی وَاَنَّ وَصِیَّهُ وَخَلیفَتَهُ عَلِ_یَّ بْنَ اَبی طالِبٍ عَلَیْهِ السَّلامُ اِمامی، وَاَشْهَدُ اَنَّ قَوْلَکَ حَقٌّ، وَاَنَّ قَضاءَکَ حَقٌّ، وَاَنَّ عَطاءَکَ عَدْلٌ(1)

وَاَنَّ جَنَّتَکَ حَقٌّ، وَاَنَّ نارَکَ حَقٌّ، وَاَ نَّکَ تُمیتُ الاَْحْیاءَ، وَتُحْیِ الْمَوْتی، وَاَ نَّکَ تَبْعَثُ مَنْ فِ_ی الْقُبُورِ، وَاَ نَّکَ جامِعُ النّاسِ لِیَوْمٍ لارَیْبَ فیهِ، لا تُغادِرُ مِنْهُمْ اَحَدا، وَاَ نَّکَ لا تُخْلِفُ الْمیعادَ

اللّهُمَّ اِنّی اُشْهِدُکَ وَکَفی بِکَ شَهیدا، فَاشْهَدْ لی یارَبِّ بِاَنَّکَ(2) اَ نْتَ الْمُنْعِمُ عَلَیَّ لا غَیْرُکَ، وَاَ نْتَ مَوْلایَ الَّذی بِاَ نْعُمِکَ تَتُمُّ الصّالِحاتُ

اللّهُمَّ اغْفِرْ لی مَغْفِرَةً عَزْما لا تُغادِرُ لی ذَنْبا، وَلا اَرْتَکِبُ بِعَوْنِکَ لی بَعْدَها مُحَرَّما، وَعافِنی مُعافاةً لا بَلْوی بَعْدَها اَبَدا، اللّهُمَّ وَاهْدِنی هُدیً لا اَضِلُّ بَعْدَهُ اَبَدا، وَانْفَعْنی بِما عَلَّمْتَنی، وَاجْعَلْهُ حُجَّةً لی، وَلا تَجْعَلْهُ (حُجَّةً) عَلَیَّ، وَارْزُقْنی رِزْقا حَلالاً مُبَلِّغا، وَرَضِّنی بِه، وَتُبْ عَلَیَّ

یا اَللّه ُ یا اَللّه ُ یا اَللّه ُ، یا رَحْمانُ یا رَحیمُ، اِهْدِنی وَارْحَمْنی مِنَ النّارِ وَاهْدِنی لِمَا اخْتُلِفَ فیهِ مِنَ الْحَقِّ بِاِذْنِکَ، اِنَّکَ تَهْدی مَنْ تَشاءُ اِلی صِراطٍ مُسْتَقیمٍ، وَاعْصِمْنی مِنَ الشَّیْطانِ الرَّجیمِ،

1- حقّ وعدل (خ ل).
2- من العلویّة و خ ل، وفی خ (فإنّکَ).
