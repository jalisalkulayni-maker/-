ص: 193

فَرْعُها مُمْرِعَةً اثارُها، غَیْرَ خُلَّبٍ بَرْقُها(1) وَلا جَهامٍ عارِضُها(2) وَلا قَزَعٍ رَبابُها(3) وَلا شَفّانٍ ذِهابُها(4) جارِیَةً بِالْخِصْبِ والْخَیْرِ عَلی اَهْلِها

تُنْعِشُ بِهَا الضَّعیفَ مِنْ عِبادِکَ، وَتُحْیی بِهَا الْمَیِّتَ مِنْ بِلادِکَ، وَتَضُمُّ بِهَا الْمَبْسُوطَ مِنْ رِزْقِکَ، وَتُخْرِجُ بِهَا الْمَخْزُونَ مِنْ رَحْمَتِکَ

وَتَعُمُّ بِها مَنْ نَأَی مِنْ خَلْقِکَ، حَتّی یَخْصِبَ لاَِمْراعِهَا الْمُجْدِبُونَ، وَیَحْیی بِبَرْکَتِهَا الْمُسْنِتُونَ(5) وَتَتْرَعَ(6) بِالْقیعانِ غُدْرانُها(7) وَتُورِقَ ذُرَی الاْکامِ رَجَواتُها(8) وَیَدْهامَّ(9) بِذُرَی الاَْ کْمامِ شَجَرُها، وَتُعْشِبَ بِها اَنْجادُنا(10) وَتَجْرِیَ بِها وِهادُنا(11) وَیُخْصِبَ بِها جَنابُنا(12) وَتُقْبِلَ بِها ثِمارُنا

وَتَعیشَ بِها مَواشینا، وَتَنْدی(13) بِها اَقاصینا، وَتَسْتَعینَ(14) بِها ضَواحینا(15) مِنَّةً مِنْ مِنَنِکَ مُجَلِّلَةً، وَنِعْمَةً مِنْ نِعَمِکَ مُفَضِّلَةً، عَلی بَرِیَّتِکَ الْمُرْمِلَةِ(16) وَوَحْشِکَ الْمُهْمَلَةِ، وَبَهائِمِکَ الْمُعْمَلَةِ

اللّهُمَّ اَ نْزِلْ عَلَیْنا سَماءً مُخْضِلَةً(17) مِدْرارا، وَاسْقِنَا الْغَیْثَ واکِفا(18) مِغْزارا، غَیْثَا مُغیثا مُمْرِعا مُجَلْجِلاً(19) واسِعا وابِلاً نافِعا

1- : لا مطر فی برقها.
2- : سحاب معترض أبیض لا ماء فیه.
3- : سُحب بیضاء متفرّقة رکب بعضها بعضاً.
4- : قلیلة أمطارها.
5- : المجدبون فی السنة.
6- تملأ .
7- المسیل الّذی یغادره الماء.
8- : أعلی التلال، نواحیها.
9- : شجرها یضرب إلی سواد الخضرة.
10- : الأراضی المرتفعة.
11- : الأراضی المنخفضة.
12- : فناء أرضنا وبأقرب منها.
13- : تَبْلُلْ.
14- فی دعاءٍ آخر: تستغنی.
15- : نواحیها البارزة.
16- : الفقیرة.
17- : مُبَلِّلة.
18- : متقاطرا.
19- : ذا حرکة وصوت.
