وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه اِبْراهیمُ عَلَیْهِ السَّلامُ وَجَعَلْتَ…

صفحة 296

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه اِبْراهیمُ عَلَیْهِ السَّلامُ وَجَعَلْتَ النّارَ عَلَیْهِ بَرْداً وَسَلاماً عَلَیْکَ یا رَبِّ، وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه اِسْماعیلُ عَلَیْهِ السَّلامُ فَفَدَیْتَهُ بِذِبْحٍ عَظیمٍ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه اِسْحاقُ عَلَیْهِ السَّلامُ عَلَیْکَ یارَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه هُودٌ عَلَیْهِ السَّلامُ فَاسْتَجَبْتَ لَهُ وَاَهْلَکْتَ عاداً عَلَیْکَ یا رَبِّ، وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه صالِحٌ عَلَیْهِ السَّلامُ فَاسْتَجَبْتَ لَهُ وَاَهْلَکْتَ ثَمُودَ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه یَعْقُوبُ عَلَیْهِ السَّلامُ فَرَدَدْتَ عَلَیْهِ بَصَرَهُ وَوَلَدَهُ وَکَشَفْتَ عَنْهُ ضُرَّهُ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه یُوسُفُ عَلَیْهِ السَّلامُ فَاَنْجَیْتَهُ مِنْ غَیابَةِ الْجُبِّ وَمِنَ السِّجْنِ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه داوُدُ عَلَیْهِ السَّلامُ فَجَعَلْتَهُ خَلیفَةً فِی الاَرْضِ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه سُلَیْمانُ عَلَیْهِ السَّلامُ فَوَهَبْتَ لَهُ مُلْکاً لا یَنْبَغی لاَحَدٍ مِنْ بَعْدِه، اِنَّکَ اَنْتَ الْوَهّابُ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه اَیُّوبُ عَلَیْهِ السَّلامُ فَکَشَفْتَ عَنْهُ ضُرَّهُ، وَاَبْرأْتَهُ مِنْ سُقْمِه عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاَسْمِ الَّذی دَعاکَ بِه مُوسی عَلَیْهِ السَّلامُ وَاَتی اِلی فِرْعَوْنَ فَاَلْبَسْتَهُ هَیْبَتَکَ عَلَیْکَ یا رَبِّ

وَاَسْاَلُکَ بِحَقِّ الاِسْمِ الَّذی دَعاکَ بِه مُوسی عَلَیْهِ السَّلامُ عَلی جَبَلِ
